## Run the Software

You can run this software online at: [https://bonihome.github.io/test/](https://bonihome.github.io/test/)

Alternatively, to run locally:
```bash
# Clone the repository
git clone https://github.com/bonihome/test.git
cd test

# Run with a local server (choose one):
# Using Python 3
python3 -m http.server 8000

# Or using Node.js
npx serve
```

Then open your browser to `http://localhost:8000` (or the port shown by the server).
